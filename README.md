# Homebrew tap

```sh
brew install darrelllong/tap/acz
```

`acz` is a file compressor built on adaptive arithmetic coding, dedicated
to the memory of Glen G. Langdon. Source: <https://github.com/darrelllong/acz>.
The formula builds from source with Rust and installs `acz`, `unacz`,
`aczcat` and the manual page.
